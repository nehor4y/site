2. Bookmark / Console Method

[1] Copy the code below
(()=>{let f=document.createElement('iframe');let v=0;f.src='https://chat-v2-eet8.onrender.com/';f.style.cssText='position:fixed;inset:0;width:100vw;height:100vh;border:0;z-index:999999;display:none';document.body.appendChild(f);document.addEventListener('keydown',e=>{if(e.ctrlKey&&e.code==='KeyQ'){v=!v;f.style.display=v?'block':'none'}});})();
[2] Paste it into your browser console (F12 → Console tab)
[3] Press Enter to run it
[4] Now press Ctrl + Q to toggle the chat overlay
[5] In case of an emergency go to the original page and press ESC which closes the chat IMMEDIATELY
