Client (how to use the chat)

[1] Download the Ch4t package
Download Chat Server (.zip)
[2] Run FindServer.bat, and click yes for admin prems
[3] If a server has been found, enter the index that correspond to the desired server
[4] Enter the password the host has gave you and you're Linked!
[5] Bookmarklet (auto loaded)
loading…
[6] Open any website and paste it into your browser URL bar
Press CTRL + Q to toggle chat
[7] Enter the IP that has been shown in the Command Prompt in this format:
wss://YOUR-IP:8765

Server hosting (LAN / school / local)

[1] Download the Ch4t package
Download Chat Server (.zip)
[2] Extract it anywhere
[3] Run RunServer.bat
If Windows complains, allow firewall access
[4] Enter a name for the server(This is the name that will be shown to others)
[5] Enter a password so unwanted people won't enter ;)
[6] And that's it! others can get linked and be in the chat
